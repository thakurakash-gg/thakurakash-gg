The scene uses authored clean geometry. No Google scanned mesh or source imagery is included in the clean context. Nearby building heights are checked against the supplied private dimensional reference where coverage permits. Context facade finishes, vegetation and road widths where unspecified are illustrative. The main architecture uses the user-supplied model, optimized for web display, with added landscape and lighting. Layout data retrieved 2026-10-15.
