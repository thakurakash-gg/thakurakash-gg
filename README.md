# Kazeyami Innovations website

Static studio website for Kazeyami Innovations Pvt. Ltd., Lucknow, India.

Open `index.html` in a browser or serve the repository with any static web server. No build step is required.

Features include a full-screen experience-center video, light/dark theme, kanji cursor trail, interactive 3D logo scene, RAY platform information, FAQs, and an enquiry form.

The enquiry form opens an email draft to hr@kazeyami.com; it does not send directly or store submissions. RAY demo integration and further project content remain to be added.
